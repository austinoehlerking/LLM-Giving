A daily hosting cron runs the bundle command at 03:17 UTC. It retains the latest 14 bundles. Source is recovered separately from the matching Git commit.

## Scope and remaining verification

The production launch starts with an empty research library. Local research records, QA fixtures, browser profiles, credentials, and development email were not published. Real user acceptance tests are the next step.

The hosting mail transport accepted a test message addressed to the operator. SPF, DKIM, and DMARC records resolve. Recipient-side delivery remains unconfirmed at the time of this record; transport acceptance is not an inbox-delivery guarantee.

ClamAV is unavailable on this hosting account. The application retains its explicit manual-review notice and conservative upload validation. No malware-detection guarantee, load certification, independent penetration test, or provider-authenticated AI provenance is claimed. Docker remains an unverified optional development route.

The full local regression suite is intentionally local-only. It was not pointed at production. Production checks were bounded route, authentication, rendering, configuration, and backup checks; the owner will perform the first real research submissions.

## Operations

- Use `/admin` for moderation and System health.
- Use the private CLI administrator command for password recovery; no default password is shipped.
- `php bin/backup-bundle.php` produces a complete private runtime bundle and retains the latest 14 generated bundles. It requires the host's tar executable. Standalone SQL backups made through the admin interface remain separately managed.
- `node tools/package-siteground.mjs` builds a source-only release. Never overwrite persistent `.env` or storage with a release.
- Restore the matching source revision, unpack a private runtime bundle outside the document root, import its SQL into the dedicated database, and verify permissions and private-path denial before reopening traffic.
- Unused-handoff pruning and inactivity archiving remain manual controls; no new automatic deletion of research or handoff evidence was scheduled.
